# Work Review UI Refresh · 原型工作区

## 本轮范围

- 只处理“应用外壳 + 概览页”。
- 保留现有导航、记录状态、统计范围、洞察、四项 KPI、今日/本周节奏、常驻网站、应用投入和域名详情能力。
- 不修改生产目录 `src/`，不重构数据接口，不扩展产品功能。

## 两个方向

### `compact.html` · 紧凑工作台

- 把四张 KPI 卡收成一条带分隔线的摘要带。
- 侧边栏、页头和数据行更紧凑，首屏能看到更多真实内容。
- 圆角只用于真正的容器和控件，不再给每一层都套大圆角。
- 已由用户选定为后续落地基线。
- 产品固定使用亮色：不显示主题按钮，也不跟随系统深色模式。

### `conservative.html` · 克制演进

- 保留当前“浅灰底 + 独立 KPI 卡 + 柔和面板”的基本观感。
- 统一圆角、边界、留白和选中态，不改变页面熟悉感。
- 适合希望视觉变化较小的落地方式。

## 可点击内容

- “今天 / 本周 / 自定义”切换。
- 分类构成条和图例筛选。
- 小时柱悬停提示。
- 常驻网站行打开详情浮层。
- 记录暂停/继续；方案 A 固定亮色，不提供主题切换。
- 其他导航会明确提示“不在本轮范围”，避免假装已经设计完成。

## 评审口径

第一轮只决定视觉骨架：侧栏密度、KPI 呈现方式、圆角与边界、内容区纵向节奏。确认方向后，再根据选定方案逐页修改原型；原型确认后才进入生产代码实现。

## 第二轮：时间线

### `timeline-compact.html` · 紧凑时间线

- 延续已确认的方案 A 和固定亮色，不创建第二套视觉语言。
- 将大卡片改为 62px 高的统一记录行，1440 × 1120 下可完整显示 12 条示例记录。
- 时间、应用、分类、活动内容、截图和时长保持清晰列结构。
- 截图缩为辅助预览，点击记录后仍可在详情抽屉查看完整信息。
- 保留日期、清理、刷新、导出、时段摘要、暂停记录和单条分类/隐私入口。
- 已由用户确认，并作为正式时间线页面的落地基线。

## 第三轮：日报

### `report-compact.html` · 紧凑日报

- 延续方案 A 的固定亮色、204px 侧栏、细边框和小圆角。
- 日期快捷入口、周日期条和页面动作收拢成紧凑操作区。
- 四项日报 KPI 合并为与概览一致的统一摘要带。
- 文章只保留一个日期标题，避免文章头和 Markdown 正文重复标题。
- 保留目录、章节编辑/置顶/隐藏、生成设置、重新生成、当前/批量导出能力。
- 已由用户确认，并作为正式日报页面的落地基线。

## 第四轮：助手

### `assistant-compact.html` · 紧凑助手

- 延续方案 A 的固定亮色、204px 侧栏、蓝色强调、细边框和小圆角。
- 参考 ChatGPT 的窄阅读轴、Gemini 的输入框内能力选择和 Codex 的任务过程表达，但不复刻任何品牌。
- 正文与输入框统一为 820px 阅读轴；助手回答直接排版，用户问题使用浅蓝色轻量气泡。
- 工具过程和回答依据默认折叠，历史会话继续使用右侧抽屉。
- 保留新对话、快捷问题、模型选择、参考记录、发送和过程查看入口。
- 已由用户确认，并作为正式助手页面的落地基线。

## 第五轮：设置

### `settings-compact.html` · 紧凑设置

- 延续方案 A 的固定亮色、204px 主侧栏、细边框和小圆角。
- 保留常规、外观、AI 模型、隐私、存储和接入管理六类设置。
- 将二级导航从大卡片中拆出，使用 166px 轻量导航轨道，减少“双层卡片”感。
- 内容统一为“分组标题 + 设置行 + 右侧控件”，更接近成熟桌面产品的设置密度。
- 保存按钮仅在产生修改后强调；标签切换、折叠、开关、分段选择、输入与保存反馈均可交互。
- 外观页固定为浅色，不再提供深色模式入口。
- 已由用户确认并完成正式设置页面实现，生产页保持六类设置与原有配置语义。

## 第六轮：护眼

### `eye-care-compact.html` · 紧凑护眼

- 延续方案 A 的固定亮色、204px 侧栏、细边框和小圆角。
- 将主计时区从大面积英雄卡压缩为 202px 状态概览，同时保留倒计时和圆环进度。
- 已观察、未计入和本轮规则合并为统一摘要带，减少重复信息。
- 计时判断依据与最近事件改为左右两栏；未计入明细使用轻分隔，不再逐项套卡片。
- 五项护眼参数和启用、暂停开关进入首屏，形成“状态 → 依据 → 事件 → 设置”的完整阅读顺序。
- 原型可切换计时、短暂离开与休息状态，并验证修改、保存反馈和 1024px 响应式。
- 已由用户确认并完成正式护眼主页实现；强制休息遮罩保持不变，休息回顾后续在第十二轮改为独立窗口。

## 第七轮：关于

### `about-compact.html` · 紧凑关于页

- 延续方案 A 的固定亮色、204px 侧栏、细边框和小圆角。
- 将品牌说明、唯一版本标识和三个常用操作集中到紧凑产品面板，移除重复版本信息。
- 版本号、自动检查开关和手动检查入口统一到右侧更新管理区。
- 产品原则改为一条三列信息带，技术栈降级为底部辅助信息。
- 赞助弹窗保留微信、支付宝和 Buy Me a Coffee，并支持点击二维码放大。
- 已由用户确认并完成正式关于页实现；GitHub、数据目录、版本更新和赞助功能逻辑保持不变。

## 第十二轮：护眼回顾窗口

### `eye-care-recap-window.html` · 独立护眼回顾窗口

- 休息结束、用户返回后，只展示独立的本轮回顾小窗口，不再唤醒 WorkBreath 主页面。
- 保留有效使用时长、主要应用和主要网站，沿用固定亮色与克制的蓝色主操作。
- 点击“继续工作”、窗口关闭按钮或 Escape 后直接关闭回顾，回到原来的工作界面。
- 没有可回顾数据时不额外弹出空窗口；锁屏和护眼计时逻辑保持不变。
