# WorkBreath v1.4.1

Work Review is now **WorkBreath** — a calmer identity for keeping work visible while giving your eyes room to breathe.

## Highlights

- Introduced the WorkBreath / 息刻 brand, the horizontal breathing-eye icon, and refreshed names across the app, installers, desktop entries, and documentation.
- Added an enabled-by-default option to lock the computer when an enforced eye-care break ends. It can be disabled from Eye Care settings.
- Implemented native screen locking for Windows, Linux, and macOS with fail-open overlay cleanup if the operating-system command is unavailable.
- Kept the save action visible while scrolling long Eye Care and Settings pages.
- Removed the square shadow leaking beyond the rounded pre-break banner.

## Upgrade compatibility

Existing data directories, update endpoints, application identifiers, and internal binary names remain unchanged, so current installations continue using their data and normal update path.

## Validation

- Frontend tests and production build passed.
- Rust `cargo check`, Clippy, and test suite passed on GitHub Actions.
- npm and Cargo dependency security audits passed.
