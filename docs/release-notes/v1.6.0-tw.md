# WorkBreath 1.6.0

## 休息視窗恢復

- Windows 明確恢復原生視窗層級及被最小化的休息視窗；顯示器佈局變化後重新定位並恢復全螢幕覆蓋。
- 單一螢幕的視窗操作失敗時繼續處理其他螢幕。僅在所有休息視窗均失焦時請求一次焦點，避免多螢幕輪流搶焦點。
- 倒數計時先訂閱狀態再讀取快照，避免遲到快照覆蓋最新狀態；載入時顯示佔位符，避免誤顯示 00:00。

## 效能與體驗

- 休息頁採用獨立入口及不透明深色視窗。入口及靜態依賴的未壓縮 JS/CSS 體積減少 52.1%；此為構建體積比較，並非 CPU 或記憶體實測降幅。
- 穩定狀態不重複調整尺寸或切換全螢幕，移除逐視窗重複的狀態事件。
- 遵循系統「減少動態效果」設定，並保留拖放導覽及右鍵選單保護。

## 依賴與升級

- 更新 reqwest 至 0.12、h2 至 0.4.19、rustls 至 0.23.45，修正 RUSTSEC-2026-0258 與 RUSTSEC-2026-0285；保留原有代理及 TLS 設定。
- 保留 1.5.11 的應用程式識別、資料目錄、更新端點及簽名公鑰，沿用既有簽名更新流程。

## 驗證

445 項前端測試、450 項 Windows 測試、461 項 macOS 測試、macOS 嚴格 Clippy、瀏覽器檢查及依賴稽核門檻均通過。Windows 測試安裝包已用 1.5.11 更新公鑰驗證簽名。

ToDesk 在 Windows 控制端本機的實測，以及從實際 1.5.11 安裝覆蓋升級，仍未完成；原生視窗層級回歸測試不能取代這些檢查。
