# WorkBreath v1.5.7

This release brings the eye-care rhythm directly into the overview so work progress and upcoming breaks can be understood at a glance.

## New

- The overview insight strip now shows the next break countdown and current eye-care cycle progress.
- Working, resting, waiting-for-return, and paused states are represented clearly.
- Eye-care reminders can be paused or resumed without leaving the overview.

## Improvements

- The overview reuses the existing eye-care status event, with no additional polling or background timer.
- The combined insight strip adapts to narrow windows without horizontal overflow.
- Browser smoke coverage now guards the main pages and settings tabs in CI.

## Validation

- 443 frontend tests, the production build, real Chromium layout checks, and the pause interaction passed.
- GitHub Actions frontend tests, browser UI smoke tests, Rust check, Clippy, and Rust tests passed before release.
