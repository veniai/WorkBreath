# WorkBreath v1.4.1

Work Review 正式更名為 **WorkBreath／息刻**：讓工作留下軌跡，也讓雙眼擁有喘息的空間。

## 重點更新

- 導入 WorkBreath／息刻品牌、橫向呼吸眼圖示，並同步更新應用程式、安裝包、桌面入口與文件中的名稱。
- 強制護眼休息結束時，預設鎖定電腦；可在護眼設定中關閉。
- Windows、Linux 與 macOS 均使用系統原生鎖定能力；若系統指令不可用，休息遮罩仍會正常退出。
- 護眼頁與設定頁捲動時，儲存操作列會持續顯示，修改長頁面後不必回到頂端。
- 移除休息預告橫幅圓角外露出的方形陰影。

## 升級相容性

既有資料目錄、更新位址、應用程式識別碼與內部主程式名稱均維持不變，現有安裝可繼續沿用原資料與自動更新流程。

## 驗證

- 前端測試與生產建置通過。
- GitHub Actions 上的 Rust `cargo check`、Clippy 與完整測試通過。
- npm 與 Cargo 相依套件安全稽核通過。
