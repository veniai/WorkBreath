# WorkBreath v1.5.8

此版本減少不必要的啟動、圖片、重新整理與狀態寫入工作，讓 WorkBreath 在日常使用時更輕巧。

## 效能改進

- 啟動時不再預先讀取時間軸、小時摘要與日報資料，改由各頁面實際開啟時載入。
- 時間軸只預載縮圖，使用者查看記錄時才載入完整解析度截圖。
- 護眼狀態的例行持久化由每 5 秒改為每 30 秒，重要狀態變化仍會立即儲存。
- 概覽頁沿用全域活動事件並合併短時間內的重複刷新，備援刷新間隔由 30 秒調整為 120 秒。

## 驗證

- 445 項前端測試、生產建置與真實 Chromium 全頁面煙霧測試均通過。
- 發布前 GitHub Actions 的前端測試、瀏覽器 UI 煙霧測試、Rust check、Clippy 與 Rust 測試均通過。
