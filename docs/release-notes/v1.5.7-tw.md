# WorkBreath v1.5.7

此版本將護眼節奏直接帶入概覽頁，讓工作進度與下一次休息時間一眼可見。

## 新增

- 概覽洞察列現在會顯示下一次休息倒數與目前護眼週期進度。
- 清楚呈現工作中、休息中、等待返回與已暫停等狀態。
- 無須離開概覽頁即可暫停或恢復護眼提醒。

## 改進

- 概覽頁沿用既有護眼狀態事件，不增加輪詢或背景計時器。
- 組合後的洞察列會配合窄視窗調整，不會產生水平溢位。
- CI 的瀏覽器煙霧測試現在會守護主要頁面與設定分頁。

## 驗證

- 443 項前端測試、生產建置、真實 Chromium 版面檢查與暫停互動均通過。
- 發布前 GitHub Actions 的前端測試、瀏覽器 UI 煙霧測試、Rust check、Clippy 與 Rust 測試均通過。
