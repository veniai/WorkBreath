# WorkBreath v1.5.8

This release reduces unnecessary startup, image, refresh, and persistence work so WorkBreath stays lighter during everyday use.

## Performance improvements

- Startup no longer prefetches timeline, hourly summary, and report data that each page already loads when opened.
- The timeline preloads thumbnails only and loads full-resolution screenshots on demand.
- Routine eye-care state persistence now runs every 30 seconds instead of every 5 seconds, while important state changes are still saved immediately.
- Overview refreshes now reuse the global activity event, coalesce bursts, and use a 120-second fallback interval instead of 30 seconds.

## Validation

- 445 frontend tests, the production build, and real Chromium smoke checks across all pages passed.
- GitHub Actions frontend tests, browser UI smoke tests, Rust check, Clippy, and Rust tests passed before release.
