# WorkBreath 1.6.0

## Rest-window recovery

- Windows explicitly restores native window stacking and minimized rest windows. Display-layout changes reposition the overlays and restore fullscreen coverage.
- A failure on one monitor no longer prevents recovery on the others. Focus is requested once when no rest window has focus, avoiding repeated focus changes across monitors.
- Countdown initialization subscribes before reading the snapshot so a late snapshot cannot overwrite a newer tick. Loading shows a placeholder instead of a misleading 00:00.

## Performance and experience

- Rest windows use a dedicated entry and an opaque dark window. The uncompressed JS/CSS entry dependency size fell by 52.1%; this is a bundle-size comparison, not a measured CPU or memory reduction.
- Stable windows avoid repeated resizing and fullscreen transitions, and duplicate per-window status events are removed.
- The rest screen respects reduced-motion preferences and retains drag-and-drop navigation and context-menu protection.

## Dependencies and updates

- Updated reqwest to 0.12, h2 to 0.4.19, and rustls to 0.23.45 to address RUSTSEC-2026-0258 and RUSTSEC-2026-0285, retaining proxy and TLS configuration.
- Preserved the 1.5.11 application identity, data directory, updater endpoints, and signing public key.

## Validation

445 frontend tests, 450 Windows tests, 461 macOS tests, macOS strict Clippy, browser checks, and dependency audit gates passed. The Windows test installer was verified against the 1.5.11 updater public key.

Real ToDesk sessions on the controlling Windows computer and installation over an actual 1.5.11 installation remain unverified. Native window-stacking regression tests do not replace those checks.
