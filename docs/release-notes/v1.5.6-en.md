# WorkBreath v1.5.6

This release fixes a Linux crash that could occur when the transparent eye-care pre-break notice was created.

## Fix

- The notice window is now shown and realized before mouse-event passthrough is enabled.
- This avoids Tao accessing a missing native GDK window during startup.
- The dedicated transparent canvas and rounded-card layout from v1.5.5 remain unchanged.

## Validation

- The v1.5.5 crash was reproduced with the published Linux package.
- An automated regression test now guards the native call order.
- Frontend tests and the production build passed. Post-fix native visual inspection was skipped by release decision.
