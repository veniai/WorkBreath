# WorkBreath v1.5.9

This release keeps the end-of-break recap focused and lightweight instead of opening the full WorkBreath interface.

## Fixed

- Returning after a scheduled eye-care break now opens the cycle recap in its own small window.
- Closing the recap returns directly to the previous work context; the main WorkBreath window is no longer revealed.
- Empty recaps are skipped, while the existing end-of-break screen lock and eye-care timer behavior remain unchanged.
- The recap can be dismissed with Continue, the system close control, or Escape, and continues to follow the configured interface language.

## Validation

- 445 frontend tests, the production build, a 720×600 recap-window check, and the main Chromium smoke suite passed.
- GitHub Actions frontend tests, browser UI smoke tests, Rust check, Clippy, and Rust tests passed before release.
