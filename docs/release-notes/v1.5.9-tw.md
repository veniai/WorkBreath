# WorkBreath v1.5.9

此版本讓休息結束後的回顧保持輕量專注，不再開啟完整的 WorkBreath 主介面。

## 修復

- 固定護眼休息結束並返回後，現在會在獨立的小視窗中顯示本輪回顧。
- 關閉回顧後會直接回到原本的工作情境，不再喚醒 WorkBreath 主視窗。
- 本輪沒有有效活動記錄時不顯示空回顧；既有的休息結束鎖定螢幕與護眼計時行為保持不變。
- 可透過「繼續」、系統關閉按鈕或 Escape 關閉回顧，並繼續跟隨已設定的介面語言。

## 驗證

- 445 項前端測試、生產建置、720×600 回顧視窗檢查與主頁面 Chromium 煙霧測試均通過。
- 發布前 GitHub Actions 的前端測試、瀏覽器 UI 煙霧測試、Rust check、Clippy 與 Rust 測試均通過。
