# Windows 实机验证矩阵

> 状态：待 Windows 10/11 实机执行。Linux 自动化、Windows 交叉编译不能替代本矩阵。

## 准备

- 使用短测试配置（例如工作 2 分钟、休息 1 分钟、自然休息 2 分钟、预告 10 秒）。
- 至少准备两块显示器，包含不同缩放比例（例如 100% + 150%）。
- 保留应用日志、`eye-care-state.json` 和必要的屏幕照片；不要用会绕过内容保护的外部采集结论代替肉眼检查。

| 默认与设置 | 新装后打开护眼设置，再修改并重启 | 默认 40/3/5/30；修改值持久化且后端边界生效 | 待验 |
| 预告 | 保持有效输入直到进入预告 | 主屏右上出现非阻塞预告；可正常点击下层应用；无延后/跳过 | 待验 |
| 双屏与混合 DPI | 在 100% + 150% 双屏进入休息 | 每屏完整覆盖；卡片约占各屏 78%；位置和文字比例正确 | 待验 |
| 热插拔 | 休息中拔出再接入副屏 | 拔出后流程不停滞；接入后 1 秒级补建覆盖层 | 待验 |
| 普通绕过 | 依次尝试 Esc、Alt+F4、最小化、Win+D、关闭主窗口 | 休息不被跳过；消失的覆盖层由 watchdog 恢复 | 待验 |

| ToDesk 输入与退出 | 休息中尝试键鼠输入和全局紧急退出组合键；在 ToDesk 开启/关闭键盘独占时分别验证 | 倒计时持续；系统快捷键出口有效；结束后 ToDesk 可恢复正常操作 | 待验 |
