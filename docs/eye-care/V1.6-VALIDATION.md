# 1.6.0 本地候选评估与验收

核对日期：2026-09-24。尚未发布。

用户已确认问题发生在 **Windows 控制端本机**，息刻与 ToDesk 都运行在操作电脑上。此次修复按本机窗口覆盖场景验证，不涉及被控端画面排除。

## 项目与基线

- 开源主线：`veniai/WorkBreath`（息刻），最新正式 Release 为 `v1.5.11`。
- 本次候选基于 `origin/main@5f0267b`，其代码树与 `v1.5.11` 相同。
- 最初会话目录属于 `veniai/WorkBreath-KylinV10`，是基于 WorkBreath 的麒麟 V10 ARM64 内网适配版，代码版本为 1.5.9。其 X11 独立遮罩、离线 OCR 和 CKAI 更新提醒不能直接替代开源版的 Windows 窗口及签名自动更新实现。
- 本地分支：`fix/v1.6-rest-reliability`。版本号已统一为 1.6.0，发布仍以验收结果为准。

## 代码排查结论

| 范围 | 结论与本次处理 |
| --- | --- |
| 全屏休息层 | 1.5.11 进入全屏后只调用 show/focus，未恢复最小化状态，也未重新抬升原生窗口层级。Windows Tao 0.34.8 的置顶 setter 在状态标志不变时跳过操作。本次增加显式 Z-order 恢复和最小化恢复。 |
| 多显示器 | 原实现每秒逐屏请求焦点，并忽略显示器数量不变时的几何变化。本次只在休息层均失焦时请求一次焦点，按物理位置/尺寸修复覆盖。 |
| 窗口失败处理 | 原来多数窗口操作失败被忽略，单个窗口创建失败会提前结束整个同步。本次记录操作失败、继续尝试显示和置顶，并继续覆盖其他屏幕。 |
| 加载与事件 | 原休息层加载主入口，且单窗口定向通知与全局广播重复。本次增加独立 HTML/JS 入口，取消重复定向事件。 |
| 倒计时体验 | 原快照和订阅并发，慢快照可能覆盖新事件。本次先订阅并防止旧快照覆盖最新状态；等待状态时显示占位符；支持系统减少动态效果设置。 |
| 计时、存储、采集 | 原有护眼状态机独立于录制/截图/OCR，使用单调时钟，并按状态变化或 30 tick 持久化。保留这些已有优化，不调整工作时长或数据语义。 |
| 自动升级 | 开源版已有平台更新包校验、多源回退和签名机制。本次保留更新端点、公钥、应用 identifier 与数据目录，不套用麒麟版的仅提醒机制。 |
| 依赖 | 未改依赖版本。npm 运行时审计发现 DOMPurify 中等严重级别公告 GHSA-55q2-fjhq-7xh7；仓库的 high 门禁通过。未把此公告当作已经验证的应用漏洞。 |

这些代码缺口与用户报告相符，但尚未在用户的 ToDesk 环境中复现，不能据此宣布唯一根因或实机修复完成。

## 性能证据

相同机器分别构建 1.5.11 和候选，统计休息入口的 JS/CSS 及其静态依赖；旧版包含主入口和动态加载的休息组件，新版只包含独立休息入口。

| 指标 | 1.5.11 | 1.6.0 候选 |
| --- | ---: | ---: |
| 入口依赖资源总字节数（未压缩） | 576,373 | 276,206 |
| 资源减少 | — | 52.1% |

这是构建产物体积比较，不代表已测得的内存、CPU 或启动耗时变化；真实多屏性能仍需在目标机器观测。

确认 Windows 控制端场景后，新增隐藏 Win32 窗口回归测试，模拟另一个置顶窗口盖住休息层，再验证原生 Z-order 恢复；不抢焦点、不遮挡开发者桌面。该测试已经交叉编译，执行结果须以 Windows 原生 CI 为准。现有 CI 已新增 Windows check/test 作业；本地护眼测试 22 项和前端定向检查 17 项再次通过。

以上均为本地自检，不是独立审查或发布验收。复验命令：

```sh
node --test
npm run build
cargo check --workspace --all-targets
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
npm audit --registry=https://registry.npmjs.org --omit=dev --audit-level=high
```

浏览器检查沿用仓库 Playwright。启动本地 Vite 后运行：

```sh
README_CAPTURE_BASE_URL=http://127.0.0.1:4186 \
README_CAPTURE_LOCALES=zh-CN \
README_CAPTURE_OUTPUT_ROOT=/tmp/workbreath-v1.6-ui-smoke \
README_CAPTURE_SKIP_GIF=1 node scripts/capture-readme-pages.mjs

EYE_CARE_CHECK_BASE_URL=http://127.0.0.1:4186/ \
node scripts/check-eye-care-overlay.mjs
```

浏览器使用模拟 Tauri IPC，验证显示、倒计时和前端交互；不能证明 Windows 原生 Z-order、远程键盘独占、系统锁屏或真实多屏行为。

## 发布前需要完成

1. 已确认 Windows 控制端本机；实机验证时记录具体 Windows/ToDesk 版本及显示器设置。
2. 执行 `WINDOWS-VALIDATION.md` 的 ToDesk 窗口/全屏、多屏混合 DPI、最小化恢复、紧急退出、结束释放与锁屏矩阵。保留本机观察和日志；内容保护可能使被控端休息窗口不出现在远程画面中。
3. 通过仓库要求的原生平台 CI、独立审查和签名安装包构建。当前 Linux 自检不能代替 Windows/macOS 原生验证。
4. 用真实 1.5.11 安装测试升级包，核实设置、历史数据、护眼计时和签名校验。正式发布前把 changelog 的 Unreleased 改成实际发布日期。
5. 发布 `v1.6.0` 后核实 Windows 安装包及签名、macOS 包及签名、三个 updater 清单的平台条目、版本和下载地址。原有 1.5.11 才能通过“检查更新”获取正式更新。

本文件记录本地验证证据；后续原生 CI、独立审查和测试构建以候选 PR/Actions 的结果为准。正式 Release、远程更新清单和用户电脑尚未改动。
